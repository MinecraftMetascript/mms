# MMS v0.5.1

41 pull requests since v0.5.0. The headline is `mms mcp`, a server that gives AI agents the same engine the editors use. Around it: named selectors, `private` names, animated textures and one-line block retexturing, a spline editor, a biome map that explains itself, and a much larger set of docs.

## Before you upgrade

A few changes alter what a project writes or accepts:

- **Block states are written as `{ id, properties }`**, the 26.x form, instead of `{ Name, Properties }`. A block state with properties, such as a tree's `trunk_provider`, used to fail with an internal error (#258).
- **A `Texture(...)` in a Model lands in `textures/block/`.** Without an id name it becomes `<ns>:block/<name>`, where the game's atlases can find it. It used to go to the root of `textures/`, which the game reported as missing (#231).
- **Selectors are checked where they are written.** An unknown option or a head such as `@q` is now an `mms/selector` error, with a did-you-mean fix (#237).
- **Helpers for ten types the game no longer has are rejected:** the features `glow_lichen`, `random_patch`, `flower`, `no_bonemeal_flower`, `emerald_ore`, `ice_patch` and `no_surface_ore`, and the structure types `village`, `pillager_outpost` and `bastion_remnant`. `GlowLichen(...)` and the rest passed `mms check` and wrote files the game rejects. Where a type was renamed, the error says so: "this version calls it MultifaceGrowth(...)" (#263).
- **`private` is a keyword.** It is still allowed as a field key or a declaration name.
- **SNBT strings that hold a double quote are single-quoted** rather than escaped, as the game writes them (#240).

## AI agents

- **`mms mcp`** is a [Model Context Protocol](https://modelcontextprotocol.io) server over stdin and stdout. Its tools: `check` (every problem with its place, fixes and related places), `explain` (the files a project or one declaration writes, and what Templates and Blueprints expand to), `test`, `fix`, `fmt`, `convert_json` (vanilla JSON to MMS), `lookup` (kinds, helpers, types, lint rules), `vanilla` (registries, ids, block states and vanilla's own files) and `docs`. Project tools take a folder or the text of one file, so an agent without file access can use them (#241).
- **Preview tools** describe as text what the editors' preview pane shows: `biomes` (biome shares over an area, the climate at a point, and why a biome wins or never appears), `density` (a noise, density function or final density over an area or down a column, or a terrain's top blocks) and `jigsaw` (the simulator, for one seed or many). They need `node`, `bun` or `deno` on the PATH (#264).
- **`mms mcp -check`** tests the server and prints the `claude mcp add` command and the `.mcp.json` entry to use. The [AI agents guide](https://minecraftmetascript.github.io/mms/docs/guides/agents) covers setup and what to do when a client does not load the server (#242).
- **`mms init` writes `.mcp.json`** with the `mms` server and nbt-go's `nbt-mcp` for structure files. An existing file keeps its other entries (#265).
- **Docs for agents:** `llms.txt` and `llms-full.txt` are served from the site's root, and every docs page is Markdown at its URL plus `.md` (#232, #246).

## Language

- **Named selectors.** A `const boss = @e[tag=boss]` or a `Template` of type `Selector` now works in raw commands (`/kill ${boss}`), and square brackets add options to it: `guards[tag=awake]` (#237).
- **Run-time coordinates.** `Positioned`, `Rotated` and `Facing` take variables, parameters, Globals, Storage fields, scores and arithmetic as whole coordinates (`Positioned(x, 64, z)`), or a name straight after `~` or `^` (`~dx`, `^step`, `~game.height`) (#238).
- **`private`** scopes a `const`, `Template`, `Type` or `Blueprint` to its file. Two files may each keep a private name of the same spelling. Declarations that write a pack file cannot be private (#251).
- **Emit consts.** A const at the top of a Blueprint's emit block belongs to each instance, and other code reads it as `name.const`, such as `ash_vents.noise_entry`. Values with no file of their own, like biome noise entries, now have a home inside a Blueprint (#256).
- **Whole numbers in union types:** `Type Tier = 1 | 2 | 3`. Fields, parameters, consts, Storage fields and `let`s check against it and complete its numbers. A `let` typed with a string union now checks its literals too (#250).
- **`index_of(list, value)`** is the reverse of `list[i]`. A miss is an error when the value is known at compile time, and `-1` at run time (#249).
- **Animated textures.** `Texture("lamp.png", animation = { frametime = 4 })` writes the `.png.mcmeta` next to the file. MMS reads the PNG's size to warn about a strip that is not a whole number of frames or a frame index past the end (#267).
- **`Retexture`** gives a vanilla block new textures and keeps its shape: `Retexture minecraft:oak_log { textures = { side = Texture(...), end = Texture(...) } }`. It writes the models, block state and item model for you (#268).
- **`JigsawStructure`** gains `spawn_overrides`, `start_jigsaw_name`, `liquid_settings`, `pool_aliases` and `dimension_padding`, so stopping mobs spawning in a structure no longer needs the raw `Structure` form (#243).
- **`BiomeSource src { ... }`** and other schema types that are not declaration kinds now say to use a typed const, with a fix that rewrites it to `const src: BiomeSource = { ... }` (#248).

## Editors (VS Code and the web editor)

- **The VS Code extension is on the Marketplace and Open VSX** as **Minecraft Metascript** (`minecraftmetascript.mms`). It updates itself, and "Switch to Pre-Release Version" gives a build of every merge to `main` (#228).
- **Spline editor.** With the cursor in a `Spline`, the Preview tab shows the curve. Drag points and derivative handles, double-click to add a point, Delete to remove one, and open nested splines. Each change is a text edit, so undo works. An empty `Spline()` starts on the first double-click (#253, #259).
- **The biome map explains itself.** A table under the map shows the six climate values at the pointer or a pinned point and the nearest multi-noise entries, with the ranges the climate misses in red. The map can show one climate parameter or a chosen biome's distance to winning, and names the biomes that win nowhere in view (#261, #262).
- **Go to definition on a vanilla id** opens vanilla's own JSON file, read-only: noises, density functions, loot tables, tags, models, block states and more (#233, #267).
- **Schema types are discoverable.** Every schema type MMS code can name (1,442 of them) has a reference entry. Hovering a type, field or value shows its shape and examples, and value completion offers each way to write it, such as `[-2, 2]` for a `ClimateParameter` (#260).
- **Command hover** shows the forms a raw command can take from the hovered word on, in the game's `/help` syntax (#236).
- **Completion** now covers Blueprint bodies (`let`, `check`, `emit`, fields, `self.`, `${...}`), typed consts and Template arguments, sound ids after `/playsound` and `/stopsound`, a Model's texture slots (read from its parent chain, vanilla models included) and selector options (#252, #254, #230, #267, #237).
- **Jigsaw simulation depth.** The Simulation tab has a Depth slider from 0 to 20, so a layout can be previewed shallower or deeper without editing the pack (#229).
- **New lints:** `structure-unknown-loot-table` (loot table ids inside structure files), `spline-order`, `texture-outside-atlas`, `model-missing-texture` and `model-mixed-atlas` (#244, #253, #231, #267).
- **New quick fixes:** move a list of ids that holds a tag into a tag declaration; add missing fields in typed consts, Template arguments and Blueprint instance fields; move a `.png.mcmeta` beside an image into its `Texture(...)` call (#245, #254, #267).

## Docs

- **Four new tutorials:** a magic wand, a wave arena, a guide book and a jigsaw dungeon (#257).
- **New guides:** keeping state, cutting repetition, Blueprints, testing functions, shaping terrain, building and playing, a tour of the editors, a spec template for building jigsaw pieces in parallel, and retexturing and remodeling blocks (#257, #246, #268).
- **The types reference** has one page per schema area and a name finder (#260).
- The README is rewritten for the current language and tooling (#239).

## Fixes

- A string shown with `${...}` in tell, actionbar, title or book text appears as plain text, not as quoted green SNBT (#235).
- `players/update_tier()` calls the function in the pack's own namespace, not `minecraft:` (#266).
- A bool assignment that reads its own target, such as `x = x && y` or `x = !x`, gives the right answer (#266).
- A command value from an execute chain that stops early is 0 rather than whatever the variable held (#266).
- `mms test` runs `function #tag`, and `minecraft:load` through the same path (#266).
- `mms test` keeps NBT types in storage, so `store result ... byte` writes `1b` as the game does. The engine now reads and writes all NBT with [nbt-go](https://github.com/MinecraftMetascript/nbt-go) (#240).
- A slow or stuck preview no longer shows the old picture forever: slow renders give way to newer edits, and a worker that stops answering is restarted (#255, #247).
- An unused Blueprint instance is reported once, at the instance, instead of over the whole Blueprint's body (#252).
- A schema error inside a union points at the value that is wrong, not at the outermost value (#258).
- Building the web editor twice with a read-only Go install no longer fails on `wasm_exec.js` (#227).
