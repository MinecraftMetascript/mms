# Project Documentation Rules (Non-Obvious Only)

- Examples in `examples/test_files/` serve as both documentation and integration tests
- Two language reference docs: `lang_ref.md` (main) and `lang_ref_improved.md` (enhanced)
- Grammar file contains comprehensive documentation comments for all language features
- Generated Minecraft configs use specific directory structure: `worldgen/dimension_type/`, `worldgen/biome_source/`, etc.
- Namespace organization follows `namespace:name` syntax for cross-references
